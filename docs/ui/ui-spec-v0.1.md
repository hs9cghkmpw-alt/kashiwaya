# かしわや UI仕様 v0.1

## 1. 顧客画面

### QR入口
- 店名
- テーブル表示
- 「この席で注文」の確認
- セッション異常時の案内

### メニュー
- カテゴリ
- 商品名
- 価格
- 売切れ表示
- 数量選択
- 備考
- カート

### 注文確認
- 商品
- 数量
- 金額
- 「注文を確定」ボタン
- 二重送信防止中表示

### 注文完了
- 受付番号
- 注文内容
- 調理/提供状態
- 店員呼び出し

## 2. 店員POS

最重要画面はテーブル一覧。

テーブルごとに:
- 空席
- 使用中
- 会計待ち
- 呼び出し
- 未処理注文
を視覚的に識別する。

### 伝票画面
- 商品別数量
- 注文時刻
- 注文元
- 調理状態
- 取消
- 追加注文
- 会計

### 会計画面
```
合計 2,500円
預かり [        ] 円
釣銭 0円
[会計確定]
```

会計確定前に金額を再計算する。確定ボタンは二重押下を防止する。

## 3. 厨房画面

新しい注文を時系列で表示。

カード:
- 伝票/テーブル
- 注文時刻
- 商品
- 数量
- 備考
- 調理開始
- 完了

タッチ操作を想定し、ボタンを大きくする。

## 4. 管理画面

- 営業開始
- レジ開始
- 売切れ
- メニュー
- スタッフ
- 現金出金
- 日次締め
- 売上
- 経理出力
- バックアップ
- 監査ログ

## 5. UI原則

- 忙しい時間でも1〜2操作で主要処理
- 重要操作は確認ダイアログ
- 破壊的操作は理由入力
- 現在状態を常に表示
- タッチ操作を考慮した大きな操作領域
- 客画面では内部IDを表示しない
- 会計確定後の変更UIを表示しない
